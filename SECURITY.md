# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security problems or accidental data exposure.

Report security concerns privately to [security@navatron.com](mailto:security@navatron.com) and include:

- the affected repository or area
- a short description of the issue
- reproduction steps or evidence, if available
- the potential impact you see

If you are unsure whether something is sensitive, treat it as private first.

## Sensitive data

Do not include credentials, tokens, secrets, customer data, or production configuration in public issues, pull requests, or discussions.
