# NavaTron

NavaTron builds next-generation AI software and the shared platform foundations behind it.

This organization is where we keep shared product foundations, selected open source tooling, and public examples that are safe to share outside our private product repositories.

## What we focus on

- AI-native product workflows
- Identity and access foundations
- SaaS portals and control planes
- Cloud platform building blocks
- Integration tooling and developer experience

## Public repository policy

Most production and customer-specific work in this organization stays private by design.

When repositories are made public here, they are intended to be reusable tooling, examples, or open source components and should never include customer data, credentials, secrets, or internal-only configuration.
